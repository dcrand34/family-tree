# Crandall / Farley family history

A single-page family-tree archive of the Crandall and Farley lines (with the Pickett, Rogers, King, Westfall, Frakes, Knaak and related families).

- Live site: https://dcrand34.github.io/family-tree/
- Everything is in `index.html` (people, sources and follow-ups are embedded as data).
- Every person carries sources with a confidence rating (Confirmed, Supported by Record, Probable). Family trees are cited as clues only.

Current edition: Iteration 45 (veteran checks), Oct 13, 2026 -- 250 people, 60 research follow-ups.
